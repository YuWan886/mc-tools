# How to Fish 存档编辑器

单文件网页版存档编辑器，适用于 Dazed Games 出品的《How to Fish》。

在线使用：<https://YuWan886.github.io/mc-tools/>

## 使用方式

1. 用 **Chrome 或 Edge** 打开 `docs/index.html`（或上面的在线地址）
2. 点击「打开存档文件夹」选择游戏存档目录：
   `C:\Users\<用户名>\AppData\LocalLow\Dazed Games\How to Fish\Saves`
3. 在左侧存档列表选择要编辑的存档（世界存档或 `local.txt`）
4. 修改后点击「保存」——会自动生成 `.bak-时间戳` 备份并原地写回
5. 其他浏览器（Firefox/Safari）自动降级为"下载文件"，需手动放回存档目录

## 功能

- **世界存档**：金钱、岛屿进度、游戏时间、马达/船皮肤、解锁开关、难度
- **玩家**：生命（游戏硬钳制 10~100）、饱食度、手持物品、背包物品（行内增删改，物品名下拉 + ID 数字双通道）、16 槽鱼饵数量
- **local.txt**：角色外观（帽子/服装/配饰 + 10 组颜色）、已解锁皮肤、图鉴击杀记录、已见服饰、语言
- **原始 JSON 面板**：直接查看/编辑完整存档，与表单双向同步
- **一键功能**：金钱改满、全岛屿解锁、全员满状态、全图鉴解锁、全部皮肤解锁
- **数据保真**：字段顺序与未知字段原样保留；`LastSave` 等大整数原样保留，不受 JS 精度影响

## 数据来源

物品/鱼饵/语言等名称全部提取自游戏安装目录
（`Assembly-CSharp.dll` 反编译 + Addressables 本地化资源解析），
并与实际存档中的 ItemID 逐一交叉验证（63=小刀、68=霰弹枪、61=钓竿、65=雷达…）。
